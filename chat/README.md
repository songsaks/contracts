# 💬 Chat App — ระบบแชทเรียลไทม์ภายในองค์กร (Real-Time Enterprise Messaging)

ระบบส่งข้อความสื่อสารแบบทันที (Instant Messaging) ขับเคลื่อนด้วย **Django Channels**, **Daphne (ASGI)**, และ **WebSocket** (URL Prefix: `/chat/`)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **การสื่อสารแบบเรียลไทม์ (Real-Time WebSockets)**:
   * รองรับการรับ-ส่งข้อความแบบทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ
   * แจ้งเตือนเมื่อมีข้อความใหม่และแสดงสถานะผู้ใช้ออนไลน์
2. **การจัดกลุ่มห้องแชทตามระบบ (App-Specific Rooms)**:
   * ห้องส่วนกลาง (General)
   * ห้องเฉพาะระบบงาน: Rentals, Repairs, PMS, Payroll, Stocks
   * ห้องเฉพาะโครงการ (`project` FK ชี้ไปยัง `pms.Project`) เพื่อให้ทีมที่ดูแลโครงการคุยงานกันได้อย่างสะดวก
3. **การควบคุมความเป็นส่วนตัว (Privacy & Access Control)**:
   * ห้องแบบสาธารณะ (ทุกคนเข้าได้)
   * ห้องส่วนตัว (`is_private=True`) พร้อมระบบเลือกผู้ใช้ที่ได้รับอนุญาต (`allowed_users`)
4. **ฟังก์ชันพิเศษสำหรับงานภาคสนาม**:
   * รองรับการส่งไฟล์แนบและรูปภาพ
   * ฟังก์ชันแชร์พิกัด GPS บนแผนที่ เหมาะสำหรับช่างเทคนิคที่ปฏิบัติงานนอกสถานที่

---

## 🗄️ โครงสร้างโมเดลฐานข้อมูล (Models)

* **`ChatRoom`**: ข้อมูลห้องแชท, หมวดหมู่ระบบ, โครงการที่เกี่ยวข้อง, สีประจำห้อง, สถานะห้องส่วนตัว, ผู้ที่ได้รับอนุญาต
* **`ChatMessage`**: ข้อความแชท, ผู้ส่ง, เนื้อหา, วันเวลา, ไฟล์แนบ, พิกัด GPS

---

## 🔗 เส้นทาง URL และ WebSocket Endpoints

* `/chat/`: รายการห้องแชททั้งหมดและหน้าต่างสนทนา
* `/chat/room/<id>/`: เข้าร่วมห้องแชทที่ระบุ
* `ws/chat/<room_name>/`: WebSocket endpoint สำหรับเชื่อมต่อ Channel Layer
