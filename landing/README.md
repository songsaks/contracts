# 🏠 Landing App — ประตูสู่ระบบและพอร์ทัลกลาง (9Com Enterprise Portal)

หน้าแรกของระบบ (Root URL: `/`) ทำหน้าที่เป็นพอร์ทัลหลักที่รวบรวมทางเข้าสู่ระบบย่อยทั้งหมด

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **พอร์ทัลทางเข้าสู่ระบบ (Central Application Launcher)**:
   * แสดงการ์ดเมนูของระบบย่อยทั้งหมด เช่น สัญญาเช่า, แจ้งซ่อม, ขายหน้าร้าน (POS), บริหารโครงการ (PMS), เงินเดือน, วิเคราะห์หุ้น AI, แชทองค์กร, แผนงาน Ops, และกระดานความรู้
2. **การแสดงผลตามสิทธิ์ของผู้ใช้ (Role-Based Visibility)**:
   * ตรวจสอบสิทธิ์จากโปรไฟล์ของผู้ใช้แต่ละคนผ่าน `user.profile.access_*`
   * การ์ดเมนูที่ผู้ใช้ไม่มีสิทธิ์จะถูกซ่อนหรือแสดงสถานะล็อก เพื่อความปลอดภัยและความเรียบร้อยของหน้าจอ
3. **การออกแบบและประสบการณ์ผู้ใช้ (UI/UX)**:
   * ดีไซน์ทันสมัย ตอบสนองทุกขนาดหน้าจอ (Responsive Design) ทั้งเดสก์ท็อป แท็บเล็ต และสมาร์ตโฟน
   * ทางลัดเข้าสู่ระบบ เข้าสู่ระบบ/ออกจากระบบ และโปรไฟล์ผู้ใช้

---

## 🛠️ โครงสร้างไฟล์ (Files)

* **`views.py`**: ฟังก์ชัน `index(request)` สำหรับเรนเดอร์เทมเพลตหน้าหลัก
* **`urls.py`**: กำหนด path `''` สำหรับเป็น root route ของโปรเจกต์
* **`templates/landing/index.html`**: โค้ด HTML และการจัดวางเลย์เอาต์หน้าพอร์ทัล
