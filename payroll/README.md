# 💵 Payroll App — ระบบบริหารเงินเดือนและสลิปเงินเดือน (Payroll System)

ระบบคำนวณเงินเดือน บันทึกผลงานการทำงาน หักภาษี ประกันสังคมขั้นบันได และออกสลิปเงินเดือน (URL Prefix: `/payroll/`)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **บันทึกรายงานผลงานรายเดือน (WorkReport)**:
   * บันทึกข้อมูลการทำงานประจำงวดเดือน: วันทำงานจริง, ขาด, ลา, มาสาย
   * บันทึกค่าล่วงเวลา (OT), ค่าคอมมิชชัน, โบนัส, และรายการหักพิเศษ
   * Workflow สถานะรายงาน:
     * `DRAFT`: แบบร่าง
     * `SUBMITTED`: ส่งรอการตรวจสอบ
     * `APPROVED`: อนุมัติแล้ว
     * `REJECTED`: ส่งกลับเพื่อแก้ไข
2. **โครงสร้างเงินเดือนพนักงาน (EmployeeSalaryConfig)**:
   * กำหนดอัตราฐานเงินเดือน (Base Salary) ของพนักงานแต่ละคน
   * กำหนดค่าเบี้ยขยัน ค่าครองชีพ ค่าวิชาชีพ/ค่าตำแหน่ง
3. **ระบบประกันสังคมแบบขั้นบันได (SSOBracket)**:
   * กำหนดช่วงเงินเดือนขั้นต่ำ-สูงสุด อัตราเปอร์เซ็นต์หัก และเพดานฐานคำนวณ (Salary Cap) ได้อย่างอิสระ
   * คำนวณเงินสมทบกองทุนประกันสังคมโดยอัตโนมัติตามช่วงรายได้
4. **ใบจ่ายเงินเดือนและสลิป (PayrollRecord & Payslip)**:
   * รวบรวมรายได้ทั้งหมด (เงินเดือน + OT + เบี้ยเลี้ยง) และรายการหัก (ประกันสังคม + ภาษี + ขาดลามาสาย)
   * คำนวณยอดรับสุทธิ (Net Pay) พร้อมระบบพิมพ์และดาวน์โหลดสลิปเงินเดือน

---

## 🗄️ โครงสร้างโมเดลฐานข้อมูล (Models)

* **`SSOBracket`**: ตารางอัตราประกันสังคมขั้นบันได
* **`EmployeeSalaryConfig`**: โครงสร้างเงินเดือนและเบี้ยเลี้ยงประจำตัวพนักงาน
* **`WorkReport`**: รายงานผลงานและเวลาทำงานรายเดือน
* **`PayrollRecord`**: สรุปยอดเงินเดือน รายรับ-รายหัก และสถานะการจ่ายเงิน

---

## 🔗 เส้นทาง URL หลัก (URL Endpoints)

* `/payroll/`: แดชบอร์ดภาพรวมเงินเดือนประจำเดือน
* `/payroll/reports/`: จัดการรายงานผลงานรายเดือนของพนักงาน
* `/payroll/config/`: กำหนดโครงสร้างเงินเดือนและตารางประกันสังคม
* `/payroll/records/`: ตารางสรุปการจ่ายเงินเดือนและพิมพ์สลิป
